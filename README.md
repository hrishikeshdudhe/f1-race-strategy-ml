# F1 Race Strategy ML

A Python-based Formula 1 race strategy simulation and machine learning project.

The project started as a race strategy simulator and evolved into a modular system that can:

- generate F1-style race strategies
- simulate tire degradation, fuel consumption and pit stops
- model changing race conditions
- evaluate and optimize candidate strategies
- train machine learning models on simulated strategy data
- use ML predictions to assist strategy selection
- compare ML-selected strategies against simulator results
- visualize strategy predictions
- run the complete workflow through a configurable CLI

The project is designed as a **software engineering and machine learning portfolio project** rather than a real-world Formula 1 prediction system.

## Architecture

The project separates simulation, machine learning and application logic into independent modules.

```text
                    CLI
                     |
                     v
            Application Layer
                     |
          +----------+----------+
          |                     |
          v                     v
     Simulation                 ML
          |                     |
          v                     v
 Strategy generation      Feature extraction
          |                     |
          v                     v
 Race simulation          Model training
          |                     |
          +----------+----------+
                     |
                     v
              Strategy selection
                     |
                     v
          Simulator comparison
                     |
                     v
              Visualization
```

The simulator provides the simulated race-time reference, while the ML model predicts the performance of candidate strategies.

This separation allows the ML system to be evaluated against independently calculated simulator results.

## Simulation

The simulation framework models a simplified race environment including:

- tire compounds
- tire degradation
- multi-stint strategies
- pit stops
- fuel consumption
- race-condition effects
- strategy constraints
- race-time calculation

Supported race conditions include:

- Green flag
- Yellow flag
- Virtual Safety Car (VSC)
- Safety Car

The simulation is intentionally simplified and is designed primarily as a controlled environment for software and ML experimentation.

---

## Machine Learning

The ML pipeline uses simulated strategy data.

The project evaluates:

- Linear Regression
- Random Forest
- Gradient Boosting

The ML workflow includes:

```text
Simulated strategies
        ↓
Feature extraction
        ↓
Training dataset
        ↓
Model training
        ↓
Model evaluation
        ↓
Hyperparameter tuning
        ↓
Candidate prediction
        ↓
ML-assisted strategy selection
```

The final strategy-selection workflow keeps training strategies separate from candidate strategies so that the model is not simply evaluated on the same strategies it was trained on.

The dataset is **synthetic and generated by the project's own simulator**. It is not historical Formula 1 telemetry.

## V10 / V11 Results

The detailed experimental results are documented separately in:

- `docs/V10_machine_learning_model_comparison_and_tuning.md`
- `docs/V11_ml_assisted_strategy_selection.md`

The V10 experiments showed that tree-based regression models were able to learn the relationships present in the simulated strategy data.

V11 extended this from prediction to ML-assisted selection of previously unseen candidate strategies and added race-condition-aware features.

These results describe the behaviour of the project's simulation environment and should not be interpreted as real-world Formula 1 performance.

## V12 Application

The final application provides a configurable command-line interface.

Run the default configuration with:

```bash
f1-strategy
```

The application reports:

- race configuration
- race-condition distribution
- training and candidate strategy counts
- ML-selected strategy
- predicted race time
- actual simulated race time
- simulator's fastest candidate
- selection gap
- generated visualization

### Command-line options

```text
--laps
--base-lap-time
--pit-stop-time
--test-size
--random-state
```

For example:

```bash
f1-strategy --laps 30 --base-lap-time 92 --pit-stop-time 25
```

Use:

```bash
f1-strategy --help
```

to see the complete command-line interface.

## Limitations

This project is not intended to reproduce real Formula 1 race strategy.

The simulation does not model many real-world factors, including:

- real telemetry
- detailed vehicle dynamics
- weather
- traffic
- overtaking
- driver performance
- team performance
- track evolution
- detailed tire temperature behaviour
- aerodynamic effects
- real-time race data

Race conditions are represented using simplified simulation parameters rather than detailed race-control or vehicle-dynamics models.

The ML dataset is synthetic and generated from the project's simulation assumptions.

Therefore, ML performance metrics and strategy-selection results describe this simulated environment and should not be interpreted as predictions of actual Formula 1 races.
